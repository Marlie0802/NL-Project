De verboden route

Situatie

Het bedrijfsnetwerk is opgesplitst in verschillende zones.

Gebruikers mogen via de webserver bij de applicatie komen, maar mogen niet rechtstreeks verbinding maken met de database.

Onderzoek de verkeersregels en bepaal welke route niet hoort te bestaan.

Netwerkzones

USER-NET

10.10.10.0/24

Werkplekken van medewerkers

DMZ

10.10.20.0/24

Publieke webservers

DB-NET

10.10.30.0/24

Interne databases

MGMT-NET

10.10.40.0/24

Beheerwerkstations

Beleid

  • USER-NET mag webverkeer naar de DMZ sturen.
  • De webserver in de DMZ mag verbinding maken met de database.
  • Alleen MGMT-NET mag systemen beheren via SSH.
  • USER-NET mag nooit rechtstreeks bij DB-NET komen.

Firewallregels

USER-NET → DMZ → TCP 443 → ALLOW
DMZ → DB-NET → TCP 5432 → ALLOW
MGMT-NET → DMZ → TCP 22 → ALLOW
USER-NET → DB-NET → TCP 5432 → ALLOW
MGMT-NET → DB-NET → TCP 22 → ALLOW

Route naar nergens

Linux routing troubleshooting · APP-07

Situatie

APP-07 kan sinds een oude netwerkproef de databaseserver DB-02 niet meer bereiken.

Internet, DNS en andere interne systemen werken normaal.

DB-02 is vanaf andere servers gewoon bereikbaar.

Netwerkdocumentatie

Systeem IP-adres Netwerk Gateway
APP-07 10.40.10.27 10.40.10.0/24 10.40.10.1
DB-02 10.50.60.20 10.50.60.0/24 10.50.60.1

$ ping -c 2 10.40.10.1 64 bytes from 10.40.10.1: icmp_seq=1 ttl=64 time=0.422 ms 64 bytes from 10.40.10.1: icmp_seq=2 ttl=64 time=0.401 ms $ ping -c 2 1.1.1.1 64 bytes from 1.1.1.1: icmp_seq=1 ttl=57 time=8.31 ms

$ ping 10.50.60.20 From 10.40.10.27: Destination Host Unreachable $ curl http://10.50.60.20:8080/health curl: (7) Failed to connect

De verkeerde deur

Situatie

Een webserver staat in een DMZ en is bereikbaar vanaf het internet.

Alleen diensten die echt nodig zijn voor bezoekers mogen vanaf internet bereikbaar zijn.

Beheer van de server hoort alleen vanaf het interne beheernetwerk plaats te vinden.

Services op de server

Poort Service Doel
80 HTTP Website voor bezoekers
443 HTTPS Beveiligde website voor bezoekers
22 SSH Beheer van de server
123 NTP Tijdsynchronisatie

Firewallregels

INTERNET → TCP 80 → ALLOW
INTERNET → TCP 443 → ALLOW
INTERNET → TCP 22 → ALLOW
MANAGEMENT-NET → TCP 22 → ALLOW

Interne richtlijn

Webverkeer mag vanaf internet naar de server.

Beheerprotocollen zoals SSH mogen alleen vanaf het interne managementnetwerk bereikbaar zijn.

Opdracht

Welke TCP-poort staat verkeerd open naar het internet?

Vul alleen het poortnummer in.
